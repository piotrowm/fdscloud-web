03 // FAQ

Focused on one job: running FDS.

Can I upload and run an .fds file now?

Not yet. The current release presents the product concept; upload, estimation and compute functions are still being built.

Does FDSCloud replace FDS or Smokeview?

No. It is cloud infrastructure around the established FDS workflow, not a replacement solver.

What will I know before launching a simulation?

The target workflow is to provide an indicative compute configuration, runtime and cost before the cloud job starts.
