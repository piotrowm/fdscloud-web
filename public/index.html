04 // FAQ

Built for FDS workflows.

Can I upload and run an .fds file now?

Not yet. This first release is the landing-page prototype only. Upload, estimation and compute functions are intentionally disabled.

Will it replace FDS or Smokeview?

No. The concept is cloud infrastructure around the established FDS workflow, not a replacement solver.

Will simulations be able to run in parallel?

The planned architecture supports independent cloud jobs, making concurrent scenario runs possible once the compute backend is implemented.

Is pricing available?

Not in this prototype. A later estimator can calculate an indicative configuration and cost before a job is launched.
