What this example is designed to show

The fastest configuration does not necessarily provide the best economic result. In this synthetic example, scaling is strong up to 16 cores, still useful at 32 cores, and substantially weaker at 64 cores. A real FDSCloud benchmark will identify this relationship for several mesh structures rather than assume that more CPU cores always produce proportionally shorter runtimes.

What we will measure for real

Each production benchmark will publish the model characteristics, FDS version, compute platform, MPI layout, wall-clock runtime, speed-up, parallel efficiency and actual compute cost. Input files or reproducible model definitions will be provided where licensing and confidentiality allow.
